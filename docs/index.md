## 工作方式

**输入故事 → 文字分镜 → 主角参考图 → 分镜图逐张确认 → 图生视频 → 合并成片**

本地输出为 512×288、12 fps；Seedance 可选择 720p / 1080p，成片为 24 fps。本版均为无声视频。0.3 新项目使用文字分镜、单主角参考图和逐镜头图片确认流程；旧项目保留文字流程。模型权重需要单独准备。先完成短片验证，再增加镜头数量和总时长。
