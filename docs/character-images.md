# 角色与分镜图片 · 0.3

[文档首页](README.md) · [使用手册](user-guide.md) · [方舟配置](seedance.md)

## 一条完整的创作流程

1. 输入故事，让本地 Ollama 生成文字分镜，编辑画面、运镜和时长。
2. 保存单主角卡：姓名与固定外观。上传一张主角参考图，或明确点击“Seedream 生成（计费）”。
3. 为每个镜头上传或用 Seedream 生成分镜图。生成分镜图之前需要已有主角参考图。
4. 检查每张图片的角色、服装、构图与动作，逐张点击“确认这张画面”。上传和生成成功本身不代表已确认。
5. 全部图片确认后，确认当前分镜版本，再选择本地 Wan2.2 或云端 Seedance 生成视频。

已确认的分镜图片用于对应镜头的图生视频。Ollama 负责文字分镜与描述，本地视频模型仍然是 ComfyUI 中的 Wan2.2，不是 Ollama。

## 上传图片与云端生成

上传接受 JPEG、PNG、WebP，单张最大 8 MB；服务端验证并规范化为本地 JPEG。图片随项目保存。可以上传全部主角图与分镜图，不调用图片 API；结合本地 Wan2.2 可在本地制作视频。

本机没有图片生成模型。Seedream 图片生成始终使用方舟云端，与右上角视频引擎选择独立：选了“本地 Wan2.2”，再点击 Seedream 生成，图片请求仍会发送到云端并计费。使用 Seedance 视频时，参考图片及分镜内容也会发送至云端。

“引擎设置”中的默认图片模型为 `doubao-seedream-5-0-pro-260628`。Seedream 与 Seedance 共用同一方舟 API Key，密钥保存在 macOS 钥匙串；两种模型需要分别开通权限。鉴权测试通过不代表图片模型已开通。

只有明确点击图片或视频生成按钮才会提交相应计费任务。保存卡片、上传图片、确认图片、切换引擎和保存配置都不会自动生成。图片费用按方舟实际请求计费，视频费用按对应视频请求计费；本应用不展示未经验证的固定价格。点击重新生成可能产生新费用，停止本地等待不保证已提交云端请求停止计费。

## 修改与确认规则

角色姓名、外观或主角参考图改变后，应重新检查相关分镜图。镜头画面内容改变会使对应图片的确认失效。旧图片保留，便于对照；可以明确确认它仍适合新的文字，也可以上传或生成新图。

只调整镜头时长不影响图片确认，但会修改项目版本，仍需要重新确认分镜后制作视频。角色草稿与文字分镜可保存；图片操作前应用会先保存未保存的文字与角色修改，再使用最新版本请求。

0.3 以前的项目默认保留纯文字视频流程，不会自动生成图片或修改项目。保存角色卡或上传图片后，项目开启图片确认流程。

## 能力边界

目前支持单主角，不做多人角色库，也没有尾帧接续下一镜头的衔接机制。共享参考图能帮助统一外观，但不保证 100% 身份一致；仍需检查人物、服装、动作、画面细节及最终视频。

真实人物参考图用于 Seedance 时，需要满足方舟官方可信素材授权要求。本应用暂不支持办理该授权，上传文件不等于完成授权。请使用符合模型及素材要求的参考图，不要将本地上传成功理解为云端已接受该素材。
